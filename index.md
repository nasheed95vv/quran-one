# Политика конфиденциальности — Коран (Studia Islam)

**Дата последнего обновления:** [впиши сегодняшнюю дату при публикации]

## Кто мы

Приложение «Коран — Studia Islam» разработано и поддерживается Studia Islam
([ссылки на каналы — см. в самом приложении, раздел «Меню»]).

## Какие данные собирает приложение

**Приложение не собирает, не хранит на сервере и не передаёт третьим лицам
никаких персональных данных пользователя.**

Приложение не требует регистрации, входа в аккаунт, не запрашивает имя,
email, номер телефона, геолокацию или любые другие персональные данные.

## Что хранится локально на устройстве

Приложение сохраняет часть данных **только на самом устройстве**
(в защищённом хранилище приложения, недоступном другим приложениям):

- Настройки оформления (тема, шрифт, размер текста, цвета)
- Список избранных аятов
- Последнее прочитанное место (для функции «Продолжить чтение»)
- Выбранный язык интерфейса
- Настройки уведомлений (какие сообщения включены, время присылки)
- Скачанный для оффлайн-прослушивания аудио- и текстовый контент Корана

Эти данные никогда не покидают устройство пользователя и не передаются
разработчику, рекламным сетям или каким-либо третьим лицам. При удалении
приложения все эти данные удаляются вместе с ним.

## Доступ в интернет

Приложение обращается к открытым публичным API для загрузки текста и
аудио Корана:
- api.alquran.cloud — текст и переводы Корана
- cdn.islamic.network — аудиозаписи чтецов

Эти запросы содержат только техническую информацию, необходимую для
загрузки конкретной суры/аята (номер суры, номер аята, выбранный чтец) —
без каких-либо личных данных пользователя.

## Уведомления

Если пользователь разрешил уведомления, приложение присылает локальные
напоминания о чтении Корана. Эти уведомления формируются и планируются
**полностью на устройстве** — они не проходят через какой-либо внешний
сервер push-уведомлений и не связаны с личностью пользователя.

## Реклама и аналитика

Приложение **не содержит рекламы** и **не использует сервисы аналитики**
или отслеживания поведения пользователя (Google Analytics, Firebase
Analytics, рекламные SDK и т.п.).

## Разрешения приложения

Приложение запрашивает следующие разрешения на устройстве:
- **Интернет** — для загрузки текста и аудио Корана
- **Уведомления** — для присылки напоминаний о чтении (по желанию
  пользователя, можно отключить в настройках)

Приложение не запрашивает доступ к камере, микрофону, контактам,
геолокации, SMS или файловой системе за пределами собственной песочницы.

## Изменения политики

Если политика конфиденциальности будет изменена, обновлённая версия
будет опубликована по этой же ссылке с указанием новой даты.

## Связь с нами

По вопросам, связанным с этой политикой конфиденциальности, можно
обратиться через наши официальные каналы, указанные в приложении
(раздел «Меню» → соцсети).
